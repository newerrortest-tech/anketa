# Анкета перед консультацией

Адаптивная анкета для телефона и компьютера. Вопросы исходного документа распределены по восьми разделам. После проверки ответов можно скачать Word (.docx).

Ответы остаются в памяти открытой вкладки, не отправляются на сервер и не сохраняются в браузере. При обновлении страницы ответы теряются. Пропущенные поля помечаются «Не заполнено». Анализы и фотографии прикладываются к анкете отдельно.

## Публикация

1. Создайте в своём аккаунте публичный репозиторий `anketa`.
2. Загрузите файлы из этого архива в корень репозитория, без внешней папки.
3. Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Дождитесь публикации и откройте https://newerrortest-tech.github.io/anketa/.

GitHub-аккаунт посетителю не нужен. Публичный репозиторий позволяет видеть код и вопросы; редактирование доступно только владельцу и назначенным участникам.

## Проверка после публикации

Откройте сайт на компьютере и телефоне. Заполните ФИО и причину обращения, пройдите к проверке и скачайте Word. Проверьте, что введённые ответы сохранились при переходах и присутствуют в документе. Отдельно проверьте доступ без VPN через Wi-Fi и мобильную сеть.

Сайт не даёт медицинских рекомендаций и не отправляет анкету специалисту автоматически.
